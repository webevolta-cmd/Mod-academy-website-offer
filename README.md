# MOD Academy — website offer presentation (WebEvolta)

Interactive 16-slide presentation. Single self-contained `index.html`
(inline CSS/JS, vector logo, QR code; fonts load from Google Fonts).

Deploys as a static site with zero configuration (Vercel, Netlify, GitHub Pages).

Slide deep links: append `#s<number>` to the URL, e.g. `/#s15` for the pricing slide.
